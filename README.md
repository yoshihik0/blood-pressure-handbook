# 血圧手帳 - Smart BP Assistant

PCやスマートフォンのブラウザで簡単・軽快に血圧を記録・管理できる、サーバーレスの静的Webアプリケーションです。

ViteやNode.jsといった複雑なビルドツールは一切不要で、`index.html` をブラウザで直接開くだけで今すぐ使い始めることができます。

👉 **[血圧手帳アプリをブラウザで開く（GitHub Pages）](https://yoshihik0.github.io/blood-pressure-handbook/)**

---

## 📸 主な機能と特徴

### 1. スマートフォンに最適化されたフラットデザイン
- 無駄な外枠（カードデザイン）を徹底的に排除し、スマートフォンの画面幅いっぱいにフィットする設計です。
- 小さな画面でも左右の余白が無駄にならず、快適に入力や閲覧ができます。

### 2. テンキーによるスマート自動入力
- 画面上のテンキーで **最高血圧（3桁）** ➔ **最低血圧（2桁）** ➔ **脈拍（2桁）** と入力するだけで、入力箇所が自動で進みます。
- 脈拍の入力が完了すると自動的に保存処理が実行されます。
- 入力中の移動案内といった煩わしいトースト通知はなく、**保存完了時の緑色の成功トーストのみ**が表示されるシンプルな設計です。

### 3. 日本高血圧学会（JSH）基準に準拠した判定
- 入力された数値から「最適血圧」「正常血圧」「I度高血圧」などをリアルタイムで自動分類し、色分けされたバッジで表示します。
- 日本高血圧学会の家庭血圧測定基準の表をいつでもワンタップで確認できます。

### 4. データのCSV保存と復元（インポート・エクスポート）
- 記録したデータは、Excel等でも開きやすいBOM付きUTF-8のCSV形式でダウンロードできます。
- エクスポートしたCSVファイルを読み込む（インポートする）ことで、別ブラウザや別端末からでもデータを引き継ぐことができます（既存データとの重複は自動で排除・マージされます）。

### 5. SVGによる推移グラフと分布分析
- **推移グラフ**: 直近10回分の血圧（最高・最低）の傾向を美しいSVG折れ線グラフで時系列表示します。
- **割合分析**: これまでの測定データの判定分類比率を、動的なSVGドーナツグラフとパーセンテージで可視化します。

## 🛠 使い方

### 1. 動かし方
- **Web上**: [GitHub Pages](https://yoshihik0.github.io/blood-pressure-handbook/) にアクセスするだけで使えます。
- **ローカル環境**: 本リポジトリをダウンロード（またはクローン）し、フォルダ内の `index.html` をブラウザでダブルクリックして開くだけで動作します。

### 2. データの保存先
- 入力したデータは、ブラウザ内の `localStorage`（ローカルストレージ）に保存されます。
- ページを閉じたり、ブラウザをリロードしてもデータは消えません。
- ※ブラウザのキャッシュや履歴を完全に削除（初期化）するとデータが消えるため、定期的なCSV保存を推奨します。
